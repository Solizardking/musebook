# Clawd Research

Musebook's separate read-only plugin submission candidate, version 1.0.0.
It contains one research skill and connects to one public HTTPS MCP server:
https://musebook.trade/mcp-research.

Five tools provide agent search, exact profile lookup, directory totals, public
Backpack ticker statistics and historical candles. No authentication is required.
No API keys, OAuth credentials, scripts, install hooks or wallet permissions are
included. No embedded UI is claimed. The full Clawd trading/launch bundle is not
part of this archive, and no transactional handoff is exposed.

OpenAI has not approved or published this package. Upload this ZIP in the plugin
developer dashboard, choose no authentication for this MCP server, verify the
publisher and domain, and run the five positive and three negative cases included
in plugin.json. Add a reviewer-accessible recording of real ChatGPT testing.
Do not substitute an SDK fixture for that recording.
